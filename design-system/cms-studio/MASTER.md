# CMS Studio · SaaS 设计规范

2026-10-28，使用已安装的 UI/UX Pro Max，本地 Vue 3 原型界面重构。

## 适用性核验

检索：`content management SaaS dashboard`、`SaaS operational dashboard`。
采用检索中适用于企业工作台的 Minimalism & Swiss Style、浅色界面、蓝色主操作、高对比文字、克制动效。工具返回的 Hero + Features + CTA 是营销落地页结构，与运营后台不匹配，因此不应用该部分；下述工作台结构按现有操作任务设计。字体使用项目已有本地字体和中文系统字体，保持离线可用。

## 信息架构

- 固定左导航：工作台、商品、网站页面、素材、网站设置；发布中心独立呈现待发布数量。
- 工作台：内容概况 → 待发布任务 → 常用操作 → 最近编辑和当前网站 → 流程指南。
- 编辑：返回列表、编辑状态、保存草稿、预览草稿；四步流程明确说明编辑、保存、预览、发布的关系。
- 发布：本次变更、检查问题、发布确认、发布历史；小屏优先展示检查区。
- 高级配置归入网站设置，日常内容运营无需进入。

## 操作与无障碍

- 每页一个主要操作，其他操作使用描边或文本层级。
- 主要按钮至少 44px 高；键盘焦点使用明确蓝色轮廓。
- 保存与发布分开：保存不改变线上快照。
- 空标题错误靠近字段，关联 aria-describedby 并定位焦点。
- 弹窗包含焦点循环、关闭后焦点恢复，背景使用 inert；发布进行时不允许中断弹窗。
- 手机导航关闭时隐藏，避免隐藏导航进入键盘序列；遮罩仅覆盖抽屉外侧。
- 保留 prefers-reduced-motion；使用原生表单和浏览器缩放。
- 375px 手机、768px 平板、1024px 笔记本、1440px 桌面；额外验证 320px。

## 运行边界

这是前端交互原型，所有发布均为模拟，不涉及真实部署、DNS 或交易。延续 `cms-studio-prototype-v1` 存储键和原始数据结构。
