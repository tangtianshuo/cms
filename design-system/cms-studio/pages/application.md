# CMS 实际应用界面

日期：2026-10-28。继承 MASTER.md 与 ui/prototype，保留原型基准文件。

## 真实数据与信息结构

- 全局入口改为 Studio 工作台；原账户概览保留在 /d/overview。
- 日常导航为工作台、商品与内容、网站页面、素材库、网站设置、发布中心。
- 高级管理容纳原有工作区、域名、资源共享、模板、模型、分组、组件、媒体、成员备份、密钥和插件；沿用各项权限条件。
- 取消 Studio 内重复的横向导航。使用左栏、顶部位置提示、编辑页返回和操作流程提示。
- 工作台仅展示可获得的真实数据。图片数量明确为可访问图片；原型待发布数量以可访问内容模型数量替代，避免伪造状态。
- 保存更新草稿；预览确认后通过发布中心校验和发布。发布状态和差异来自真实服务。

## 实施规范

- 240px 侧栏、72px 顶栏、浅灰画布、白色表面、蓝色主操作、7–10px 圆角；手机顶栏 64px。
- 统一语义令牌覆盖浅色与深色模式。表单、按钮、弹窗、空状态、列表、表格、通知和登录框架共享规范。
- 手机导航使用 Dialog，隔离背景、限制焦点、支持 Escape 关闭并返回键盘触发按钮。
- 保留复杂内容的完整编辑器和虚拟表格；表格在自身容器内滚动。
- 本项目 Tailwind important:true，先移除冲突的旧控件 utility，必要的兼容样式集中在 _studio-theme.scss 边界内。
- 界面动效遵守 prefers-reduced-motion。可交互图标提供中文可访问名称。
