# CMS 唯一内容编辑工作区补充设计

日期：2026-11-06。需求来源：用户要求收拢 CMS 内容编辑入口，只保留一处内容编辑，边编辑边预览；本期使用模板预制排版，后续开放自由排版。

本补充覆盖 2026-10-31 可视化页面编辑器设计中关于多个编辑入口、先保存再预览及内容/页面分别操作的安排。沿用模板契约、草稿/发布分离、站点授权和并发保护，不重写发布链路。任务映射：B4 属性控件、B5 入口、B6 内容能力、B7 编辑会话与实时预览、B3/D1/D2 验收。

## 唯一入口与范围

- 侧栏只保留“网站内容”作为内容管理入口；列表、搜索、工作台、建站向导、页面及引用快捷链接都进入 `/d/studio?section=content` 下的同一个编辑工作区。
- 页面、商品、首页、品牌/联系资料、其他内容模型复用一个编辑组件、一个本地编辑会话和一套保存反馈。页面列表与商品列表可保留为内容分类，不能各有另一套编辑表单。
- 旧 `/d/template/:templateId/entry/:entryId`（含 `create`）、旧页面设置深链均解析授权上下文后转到同一工作区；保留 workspace/site、条目、语言、分组和页面定位。查找失败或无权限明确提示，不能默认打开另一站点。
- 未安装到站点的历史内容模型也在同一工作区编辑，复用既有字段组件；尚无模板页面绑定时说明“此内容尚未关联网站页面”，保留内容编辑能力，不伪造预览，不转回另一编辑器。模型结构管理、域名、素材库、发布管理仍是各自管理功能；其中涉及网站内容/导航的编辑动作跳回唯一工作区。
- 完整站点预览可保留为只读检查，不承担独立编辑；移除“高级编辑/完整编辑器”内容操作入口。原有受支持字段、语言、状态、分组能力不得因收口而丢失。

## 编辑与预览

- 桌面工作区延续左侧页面/区块导航、中间真实模板画布、右侧内容/属性/SEO 的布局。内容和页面设置可以在属性面板分组，但画布持续存在，不必先保存或打开另一个预览页。
- 文本、富文本、图片、引用、区块、导航和 SEO 共用本地草稿；输入自动触发预览，300ms 防抖。中文输入法组合输入结束后再发送；隔离验收环境中最后一次有效输入后 1 秒内可见对应结果（资源初次加载时间另记）。小屏允许属性/画布切换，切换保留修改和滚动上下文；不要求 390px 强行并排。
- 预览使用站点安装的精确模板版本、同一布局及内容转换逻辑。服务端只在内存合并草稿并构造预览，不写 Entry/SiteInstallation/Release、不触发 Gateway。商品/引用被多页面使用、品牌和导航为全局数据时，预览中所有相关页面一致更新。
- 每次编辑会话有独立 `sessionId`，每次输入递增 `revision`；响应只在当前 workspace/site/language/目标、sessionId、revision 均匹配时采用。切站/切语言/离开时取消请求并销毁旧会话。iframe 的 origin、source、模板版本和页面/节点身份校验继续生效。
- 点击画布区块选中左树及右侧属性；字段输入更新画布，不改变焦点和光标。本期采用相邻面板编辑，不要求在 iframe 内直接输入文本。
- 预览不可用时，保留可编辑草稿并显示重试；无效输入时标注字段和“预览显示上一次有效内容”，不能把旧画面描述为最新结果。新建内容/页面在内存构造临时草稿，用户可在首次保存前预览；临时 ID 不作为已发布条目持久化。

## 内容与保存

- 富文本在此工作区嵌入既有正文组件，保留结构化节点、链接、列表、媒体和支持的 widget；数组、引用、日期等使用现有受控字段组件。未知类型保留原值并只读说明，已支持类型不能统一降级为只读；必填但不受支持的字段阻止创建并提示管理员处理契约。
- 一次“保存草稿”提交当前会话中允许修改的内容、页面、导航/站点内容，顶层统一显示未保存/保存中/部分保存/冲突/已保存。后端仍可分请求执行，界面不得宣称跨集合原子保存。
- 顺序保存内容 → 页面 → 站点设置；后两者共享站点版本时用每次成功返回的最新版本。任何一步失败立即停止，成功部分记录已确认版本，未完成部分和本地修改保留。重试只提交未完成部分，不自动覆盖冲突、不重复新建。保存中禁用修改和重复提交；所有部分成功才显示“草稿已保存”。
- 保存前校验整份本地草稿，字段错误可定位。冲突显示保留本地/查看服务器版本的恢复操作；重新加载必须由用户明确放弃本地变更，不能静默覆盖。切换页面、站点、语言、退出和关闭窗口统一检查脏状态。
- `content.write` 与 `pages.manage` 分别控制可写部分；只读用户可查看授权内容。预览、保存、媒体和引用解析均校验租户、站点和内容权限；UI 隐藏按钮不能替代服务端验证。保存不会发布；仍需明确发布更新后公开站点才变化。

## 模板排版及后续扩展

本期只使用模板蓝图和声明的区块、变体及顺序能力，`LayoutDocument.version=1, mode='template'`；预制样式由模板负责。不能添加未声明区块、容器、任意 CSS 或像素定位。界面不暴露无法使用的自由排版开关。

保留现有稳定节点 ID、布局版本和兼容投影。后续自由排版必须继续使用本工作区，单独设计 `structured` 模式、受控容器/栅格、响应式能力、契约声明及旧内容迁移，并通过保存/预览/发布一致性验收后开放。该后续阶段不阻塞本期，也不在本轮计划中冒充已交付能力。

## 放行条件

1. 所有编辑链接进入同一工作区，旧书签和新增内容可用；不存在第二套用户内容编辑页面。
2. 两模板的首页、商品、联系页、品牌资料及富文本均在工作区完成编辑；不接触 JSON、不跳出到完整编辑器。
3. 不保存、不点击预览即可看到最后一次有效修改；桌面/手机、首次新增、快速输入、乱序响应、切站、预览故障有真实浏览器证据。
4. 未保存修改和保存后的草稿均不改变公开站点；显式发布后与画布一致。
5. 部分保存、并发冲突、权限不足、断网、离开提示均保留正确状态；未完成部分不能被标记为已保存。
6. 模板预制排版可用，服务端拒绝自由排版越界请求；原有数据和语言不丢失，10 分钟建站验收全程使用唯一工作区。
