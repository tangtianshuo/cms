# Storefront Workspaces Phase D3 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to execute the tasks sequentially, with task review and a final integration review. The user's 2026-10-23 instruction authorizes continued development on a new branch, including domain access and multiple sites/workspaces.

**Goal:** 在一个 CMS 实例中建设多个电商独立站，允许多个整站模板及其安装实例共存，通过域名定位工作区和站点，并支持 Entry 分组及受控资源共享。

**Architecture:** Workspace 是资源归属与权限边界，Site 是页面、主题安装、域名和 Release 的发布边界；一个工作区可管理多个站点。域名全局唯一，解析为 workspaceId + siteId；域名不是管理员权限凭据。平台预制包和受控主题组件可以共用，安装结果及发布状态按站点保存。跨工作区共享使用显式授权和复制导入，引用共享资源时固定版本，发布快照不随源工作区草稿变化。

**Tech Stack:** 现有 TypeScript、Fastify、MongoDB、Vue 3 管理端、Nuxt Storefront；复用 JWT 与现有仓储，不新增租户数据库或任意代码执行。

**Spec:** 本文“产品与数据约定”，以及 `docs/architecture/storefront-preset-solution.md` 第 6.3 节。域名实施细节见 `2026-10-23-storefront-domains-phase-d1.md`。

## 产品与数据约定

- 状态：新增需求，已授权实施；完成情况以任务记录和实际验收为准。开始前发现阶段 C 已由提交 d518158 完成，先复核其验收与当前基线。
- `Workspace` 拥有稳定 ID、名称及成员权限；创建者和实例 ADMIN/SUDO 可以管理，普通成员仅访问获授权的工作区。管理端提供明确的工作区和站点选择；域名解析不能授予管理权限。
- `SiteInstallation` 增加 workspaceId 与站点身份，移除全局唯一 default 安装限制。同一或不同预制包可分别安装到多个站点；每站点仍固定一个主主题版本，可有布局变体。不同模板和站点安装互不覆盖。
- 域名解析链路：受信任请求主机名 -> SiteDomain -> Workspace + Site -> 当前 Release。域名绑定属于站点，同一站点可有多个域名；不同工作区允许相同页面路径。
- 内容 Template、Entry、媒体、组件/Widget 记录 workspaceId，查询、写入、引用解析、预览、导出及实时同步在服务端检查工作区；客户端传入 ID 不能绕过归属和成员校验。
- `EntryGroup` 是工作区内的内容分组，与现有定义字段结构的 CMS Group 分开建模。Entry 有明确 groupId；未分组内容进入默认组。
- Entry 名称使用现有多语言 title：在同一 workspaceId + groupId + language 下，NFKC 规范化、去首尾空白和忽略大小写后唯一，跨内容模型也不能同名；不同组或不同工作区允许同名。创建、重命名、复制、导入和移动组都执行同一规则，数据库唯一约束处理并发。Slug 的公开路由冲突仍由站点发布校验处理。
- 历史数据迁入默认工作区与默认组，保留原 ID、字段映射、媒体 URL 和 Release。迁移先报告冲突，不删除或静默重命名历史内容；未完成迁移时不得把旧数据暴露给新工作区。
- 共享对象包含 Entry、媒体和受控组件/Widget，保留 ownerWorkspaceId、资源类型/ID、目标工作区、允许的使用方式、版本与审计。默认私有；同属一个实例不意味着可以读取或编辑。
- 首期交付显式“共享给工作区”和“复制到当前工作区”：目标获得独立副本，Entry 按目标内容模型字段映射并选择组，媒体与组件依赖一并校验；资源缺失或不兼容时完整失败，不留下可用的半成品。共享读取授权不包含源资源写权限。
- 共享版本引用与复制在界面上明确区分；受控版本引用必须在发布时解析成快照，源资源后续编辑、撤销共享或删除不改变已发布内容。首期以可独立维护的复制导入为必交付，持续同步另行扩展。
- 共享撤销阻止后续读取/导入；已复制内容归目标所有。物理媒体被发布版本或副本引用时不得直接清除，需显示依赖并保留文件，防止共享后源删除导致网站图片失效。
- 共享授权不自动开放私有原文、凭据、关联 Entry 或其他依赖；只返回显式分享的资源，依赖须获得授权或在复制时明确拒绝。
- D1 可先按单站点完成，再在本阶段启用多工作区；D2 报表查询复用本阶段工作区归属。主题升级迁移、CDN 缓存清理及其他运营扩展另列 D4。
