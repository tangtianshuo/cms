## 范围与设计

使用 UI/UX Pro Max，沿用原型浅灰画布、白色表面、蓝色主操作、240px 左栏、72px 顶栏、28px 标题及 44px 控件。检索返回的玻璃风和营销落地页布局不符合已批准原型，不采用。保留用户既有深色偏好，并补充对应语义令牌。

日常导航为工作台、商品与内容、网站页面、素材、网站设置、发布中心。模板模型、成员语言与备份、域名、共享、密钥、插件集中到高级管理，权限规则保持。移除 Studio 重复横向导航。所有页面共享位置提示和响应式抽屉。编辑过程显示编辑→保存→预览→发布，并保留脏数据离开保护。

工作台使用真实内容数量、常用操作、最近编辑、网站信息与流程指引；不伪造发布数量或在线状态。商品和页面列表增加本地搜索与空结果反馈。高级页面、富文本编辑、素材管理、公共表单、表格、弹窗、通知及登录视觉同步统一。
