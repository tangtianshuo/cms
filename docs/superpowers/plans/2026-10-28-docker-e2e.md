# 本地 Docker 全流程验收计划

**目标：** 以当前工作区构建独立容器栈，验证 CMS 编辑、预览、发布、路由、页面生命周期、失败保护和回滚，并保存可复跑证据。

**环境：** Docker Desktop、MongoDB 7、PostgreSQL 18、实际 CMS 生产入口、Gateway control、真实 Docker worker 和 Nuxt 模板镜像。全部宿主端口只监听 loopback，独立 compose 项目与数据卷，不读取现有生产 .env，不覆盖原容器或数据库。

**边界：** AeroFrame 1.0.3 尚未登记公开索引，不能伪造发布记录。1.0.3 验证本地构建、镜像运行和私有预览；跨仓公开发布链路采用真实已发布、不可变的 1.0.2。Docker Desktop 上 worker 按现有宿主进程设计运行，通过 Docker socket 启动真实候选容器。公网 ACME/HTTPS 和远端部署不属于本地验收。

## 首次验收发现（修复前）

核心发布链路和计划内测试已执行。额外的连续发布资源审计发现：旧站点容器未自动回收（13 个实例中 11 个已无路由引用）。当时仅手工清理了隔离测试的冗余实例，自动回收尚未实现。后续已按用户追加要求修复并通过真实 Docker 验收，结果见下文与验收报告；本地通过仍不代表公网/HA 等生产全项验收。
