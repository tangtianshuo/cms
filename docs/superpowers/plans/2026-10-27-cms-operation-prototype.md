# CMS 操作简化交互原型

目标：将已讨论的站点选择、任务概览、商品与页面编辑、预览和发布方案制作成可浏览的前端原型。

实现范围：独立入口 `ui/prototype/index.html`，使用现有 Vue/Vite 依赖，演示数据只存入带版本号的浏览器 localStorage。原型不调用业务 API。

- [x] 制作统一应用框架、站点选择器和任务概览。
- [x] 制作商品列表、页面列表、编辑表单、素材选择和桌面/手机草稿预览。
- [x] 制作发布前校验、问题定位、变更确认、发布状态与历史记录。
- [x] 串起创建站点、模板选择和新站建站清单。
- [x] 在浏览器验证修改、保存、预览、发布、新建页面、站点隔离与窄屏布局。

设计约束：中文运营界面；页面和内容一次创建；发布入口全局可见；草稿与线上版本明确区分；未保存离开有保护；重置演示可恢复初始数据。

验收场景：修改首页并发布；新增关于我们页面；新增商品；制造必填错误后定位修复；切换站点不混淆草稿；创建新站后完成清单。

验证结果：
- 独立 `vue-tsc --noEmit -p prototype/tsconfig.json` 通过。
- 独立 Vite 构建通过，无构建警告。
- 浏览器完成首页修改、保存、390px 手机预览、发布确认、版本生成与待发布数量归零。
- 缺少商品简介和价格时发布被拦截；点击错误聚焦 `field-price`，修复后通过校验。
- 新增品牌故事页自动生成路径并进入待发布列表。
- 未保存离开提示与放弃修改分支通过。
- 切换 Forma 后显示独立的 0 项待发布；创建新站后显示建站清单。
- 1440px、390px、320px 页面无横向溢出；320px 预览区域无溢出。
- 独立静态构建资源加载正常，浏览器无 error/warn 日志。

交付：`ui/prototype/` 源码；`deliverables/cms-studio-prototype/` 静态构建；`deliverables/cms-studio-prototype-review/` 截图。
