## 需求与边界

本轮交付 D1 域名能力与 D3 多独立站、多工作区能力。一个工作区可以管理多个站点，同一或不同建站模板可在多个站点独立安装；域名定位到工作区及站点，各站点分别维护页面、主题和不可变发布版本。

Workspace 是资源与权限边界，Site 是安装与发布边界。域名、客户端工作区和站点选择只用于定位，服务端仍须验证成员资格、内容权限和资源归属。历史未标记数据只属于默认工作区，迁移保留原 ID、字段映射、媒体 URL 和已有 Release。

Entry 分组与定义字段结构的 CMS Group 是两个概念。同一工作区、分组、语言下，Entry 的 title 经 NFKC 规范化、去首尾空白及忽略大小写后唯一，跨 Template 也不能同名；不同组或工作区可同名。

跨工作区共享首期采用显式授权、固定版本、独立复制。源修改或撤销授权不能修改已接受的副本或已发布内容。持续同步、D2 访客统计和 D4 运营扩展不属于本轮实现。

### 域名与公开访问

已实现域名规范化和全局唯一、限时 TXT 归属验证、受控 HTTPS 挑战、启停、解绑、主域名切换和审计。公开请求通过受信任网关解析到对应站点的不可变 Release，包含 canonical、sitemap 和别名重定向；未知、未验证、停用或没有发布版本的站点返回 404。

主域名指针、版本与审计 outbox 原子保存；后续审计投递失败不能将已提交成功误报为主域名切换失败。草稿保存及模板导入须保留域名、审计和发布操作字段。DNS、证书和 CDN 仍由外部平台维护。

### 多工作区与内容隔离

已实现工作区和成员管理、站点列表和创建、按请求验证的工作区上下文、按站点命名空间安装模板，以及默认站点兼容。删除工作区使用持久化创建许可与版本条件，防止并发创建造成孤立资源。

内容隔离覆盖仓储、自定义查询、缓存、媒体、预览、Socket 和 MCP。实例 ADMIN/SUDO 与工作区成员管理员有不同权限：工作区管理员仍受 Template/Media 内容授权约束。SUDO 要求数据库中存在对应角色的最新用户身份，不支持只在 token 中临时声称 SUDO。

EntryGroup 已提供创建、改名、删除空组和移动 Entry，数据库唯一索引约束名称。历史迁移可先预览冲突，不会静默改名或删除内容；正式迁移要求暂停相关写入。

### 共享与复制

已实现 Entry、Media、Widget 和结构 Group 的显式版本授权、预览、撤销及复制。Entry 复制需要目标 Template、分组和完整字段映射；依赖资源必须另有显式授权。

复制使用持久化批次提交屏障，提交前的暂存记录不可通过普通查询使用；媒体复制生成独立文件，记录来源和版本。撤销与复制通过持久化许可协调，发布媒体使用保守保留策略防止已发布图片被删除。

### 管理端

已加入工作区与站点选择、创建和成员管理、建站模板安装、域名管理、Entry 分组筛选/移动、共享授权/预览/复制映射，以及中英文文案。共享复制使用常规表单控件，可指定目标模型、分组和依赖字段映射，并展示独立副本与来源信息。

SDK 与 Socket 携带同一已验证上下文。切换时停止旧 Socket、使旧请求失效、清理资源状态并整页导航；失效的已保存选择有恢复入口。整页切换会丢弃未保存编辑状态。

私有媒体使用短时能力令牌，管理端定期刷新元数据，页面及商品 iframe 预览定期续期；共享媒体通过认证请求获取 blob 并回收对象 URL。上述管理端行为仍待独立审查及运行验收。
